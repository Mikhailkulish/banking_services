# banking_services
Приложение предназначено для обслуживания клиентов банка. Позволяет управлять счетами пользователя, выполнять переводы,
пополнения и проверять баланс.
## Установка и использование
Чтобы установить и запустить проект, нужно выполнить следующие действия:
* клонировать репозиторий, использовав ссылку с аккаунта GitHub;
* установить poetry командой pip install poetry;
* установить зависимости, введя poetry install;
* активировать виртуальное окружение командой poetry shell;
* запустить приложение с помощью python main.py
### Доступный функционал
С помощью приложения можно воспользоваться следующими функциями (в скобках указано расположение):
* get_mask_card_number (.\src\masks.py) - выдает маску карты;
* get_mask_account (.\src\masks.py) - выдает маску счета;
* mask_account_card (.\src\widget.py) - обрабатывает информацию о картах и счетах;
* get_date (.\src\widget.py) - преобразует дату по стандарту ISO 8601 в формат "ДД.ММ.ГГГГ";
* filter_by_state (.\src\processing.py) - фильтрует данные по ключу;
* sort_by_date (.\src\processing.py) - сортирует данные.
* filter_by_currency (.\src\generators.py) - выдает итератор для фильтрации списка словарей с информацией о транзакциях по валюте;
* transaction_descriptions (.\src\generators.py) - поочередно возвращает описание транзакций;
* card_number_generator (.\src\generators.py) - генерирует номера карт в заданном диапазоне;
* load_transactions (.\src\utils.py) - загружает финансовые транзакции из JSON-файла;
* convert_to_rub (.\src\external_api) - принимает транзакцию в виде словаря и возвращает сумму в рублях;
* load_transactions (.\src\reading_transactions) - считывает файл CSV с информацией о транзакциях, выдает список словарей с транзакциями;
* load_transactions_excel (.\src\reading_transactions) - считывает файл Excel с информацией о транзакциях, выдает список словарей с транзакциями.
Разработаны тесты в pytest для проверки корректности работы функций, в том числе с применением инструментов Mock, patch, фикстур, параметризации. Создан файл .env, содержащий переменные окружения. Функционал приложения в процессе разработки.
## Пример использования
После запуска приложения пользователю будет предложено меню с доступными функциями. При переходе к определенному разделу
можно выполнить необходимую транзакцию, получить информацию или совершить иное действие, в соответствии с возможностями
сервиса.
Подробная информация с примерами будет отражена после полной разработки функционала.
